## Files
- `index.html` is the whole website
- `img/` holds the photos and the church logo
- `thankyou.html` is shown after a form is sent

## Updating the site
1. Open the repository and select `index.html`, then the pencil icon.
2. Change the text, then choose "Commit changes".
3. The live site updates within a few minutes.

To add a photo, choose Add file, then Upload files, and put it in the `img` folder.

## Forms
The prayer request and testimony forms send to the church email through FormSubmit. The first time a form is used, FormSubmit sends a confirmation email to the church address. Confirm it once, and requests will then arrive normally.

## Turning on the website
Go to Settings, then Pages. Under Source choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
